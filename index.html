Cashback Tracker Privacy Policy

Effective October 17, 2026

1. Summary

Cashback Tracker stores its primary data locally and requires no registration. The developer does not receive, store, or process financial data entered in the app on developer-operated servers. Data may reach a third party only through an action you choose: when the backup folder is managed by an external file provider or when you use Bluetooth synchronization.

2. Data you create

You may enter accounts, cards, transactions, categories, limits, goals, and recurring payments. This information is stored locally in the app database on your device.

3. Data transfer

The app does not send data to the developer and does not use advertising or analytics SDKs. To create or restore a backup, you select a folder or file through the system picker. If the selected folder is on a cloud drive, the operating system and provider app transfer and store the file under that provider's terms. Cashback Tracker does not call the Google Drive or Yandex Disk APIs directly. Shared-account synchronization sends an encrypted copy directly to the selected device over Bluetooth.

4. System services

The system file picker determines which locations are available and gives the app access only to the folder or file you select. Google Drive, Yandex Disk, and other storage providers appear there only when an installed provider app exposes files to the system. Cashback Tracker does not sign in to those services, receive your password, or store OAuth tokens. Your operating system and app store may also process technical information and make system backups independently of the developer.

5. Permissions

The app may request Bluetooth and nearby-device permissions for direct synchronization. Older Android versions also require system location permission for Bluetooth discovery; the app does not read or store coordinates. Access to a selected folder or file is used only to create and restore backups. A file provider may require an internet connection to synchronize a folder with the cloud.

6. Control and deletion

You can edit or delete data in the app. Uninstalling removes local app data according to operating-system rules, but does not delete backup files from the selected external folder. Delete them with the system file app or the storage provider's app. You can end folder access through the operating system or by selecting a different folder in Cashback Tracker.

7. Security and your responsibility

A backup file contains readable financial history and is not encrypted by the app. You are responsible for choosing a trusted folder, protecting connected storage, securing the device, and selecting a trusted Bluetooth peer.

8. Changes and contact

Updates to this policy will be published on this page. Privacy questions: krasnonos.d@gmail.com.

9. Contacting support

If you email us, we receive your email address and the information you choose to include. We use it to answer your request and retain it only as needed to handle the enquiry or meet applicable legal obligations. Email is handled by our email provider, Google (Gmail). Please avoid sending financial records unless needed for your request.

10. This website

This policy page is hosted on GitHub Pages. We do not add analytics, advertising scripts or tracking cookies to this page. GitHub logs visitors’ IP addresses for security purposes. See the GitHub Privacy Statement. This website hosting is separate from the app’s local financial data storage.
