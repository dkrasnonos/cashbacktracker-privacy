Политика конфиденциальности Cashback Tracker

Редакция от 17 октября 2026 года

1. Кратко

Cashback Tracker хранит основные данные локально и работает без регистрации. Разработчик не получает, не хранит и не обрабатывает введённые в приложении финансовые данные на своих серверах. Данные могут передаваться третьей стороне только по выбранному вами действию: если папка для резервных копий обслуживается внешним поставщиком файлов или при Bluetooth-синхронизации.

2. Какие данные создаются

Вы можете вводить сведения о счетах, картах, операциях, категориях, лимитах, целях и регулярных платежах. Эти сведения сохраняются локально в базе данных приложения на вашем устройстве.

3. Передача данных

Приложение не отправляет данные разработчику и не использует рекламные или аналитические SDK. Для создания или восстановления резервной копии вы выбираете папку либо файл через системное окно. Если выбранная папка находится на облачном диске, передачу и хранение файла выполняют операционная система и приложение поставщика по его правилам. Cashback Tracker не обращается к API Google Drive или Яндекс Диска напрямую. При синхронизации совместного счёта зашифрованная копия передаётся напрямую выбранному устройству по Bluetooth.

4. Системные сервисы

Системное окно выбора файлов определяет доступные места и выдаёт приложению доступ только к выбранной вами папке или файлу. Google Drive, Яндекс Диск и другие хранилища отображаются в нём, только если установленное приложение поставщика предоставляет системный доступ к файлам. Cashback Tracker не выполняет вход в эти сервисы, не получает пароль и не хранит OAuth-токены. Операционная система и магазин приложений также могут обрабатывать технические сведения и создавать системные копии независимо от разработчика.

5. Разрешения

Для прямой синхронизации приложение может запросить разрешения Bluetooth и поиска ближайших устройств. На старых версиях Android поиск Bluetooth-устройств также требует системного разрешения геопозиции; приложение не считывает и не сохраняет координаты. Доступ к выбранной папке или файлу используется только для создания и восстановления резервных копий. Для синхронизации папки с облаком поставщику файлов может потребоваться подключение к интернету.

6. Управление и удаление

Данные можно изменять или удалять средствами приложения. Удаление приложения удаляет локальные данные по правилам операционной системы, но не удаляет файлы резервных копий из выбранной внешней папки. Их нужно удалить через системное приложение для файлов или приложение поставщика хранилища. Доступ к папке можно прекратить средствами операционной системы или выбрав в Cashback Tracker другую папку.

7. Защита и ответственность пользователя

Файл резервной копии содержит финансовую историю в читаемом виде и не шифруется приложением. За выбор надёжной папки, защиту подключённого хранилища, блокировку устройства и выбор устройства для Bluetooth-синхронизации отвечает пользователь.

Мы используем их для ответа и храним только столько, сколько необходимо для обработки обращения или выполнения требований закона. Почту обслуживает Google (Gmail). Не отправляйте финансовые записи, если они не нужны для вашего обращения.
